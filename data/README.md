# E-commerce Sales Analysis

## About the Project

This project explores online retail transaction data to identify sales trends, customer purchasing patterns, and product performance.

## Objectives

- Analyze revenue and sales dynamics.
- Identify best-selling products.
- Explore customer purchasing behavior.
- Calculate key business metrics.
- Discover patterns in retail transactions.

## Tools & Technologies

- SQL (PostgreSQL)
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Structure

- `data/` — dataset documentation
- `sql/` — SQL queries and analysis
- `notebooks/` — exploratory data analysis
- `reports/` — visualizations and findings
